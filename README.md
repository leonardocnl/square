# Square

Modernização desktop do [Sweet Home 3D](https://www.sweethome3d.com) 7.5:
a lógica original do SH3D, com interface (Compose) e 3D (jMonkeyEngine) novos.

Veja `CLAUDE.md` para as regras e `docs/` para arquitetura e progresso.
